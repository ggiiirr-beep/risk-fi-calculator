# Blue — podcast character reference

The owner selected [blue-reference.jpg](blue-reference.jpg) on October 23, 2026 as the consistent character model for From Paychecks to Purpose. This is the primary reference for future character artwork, superseding the character details in the first website hero prompt. Keep the supplied sheet intact.

## Recognizable features

- Light-blue skin; shoulder-length black hair with a side part and softly curved ends.
- Round gold glasses and a minimal, mostly featureless face. Do not add realistic facial details by default.
- Mustard/golden sweater with full sleeves, navy knee-length skirt and dark-blue flat shoes as the default outfit.
- Clean dark outlines, flat blue/gold colors and restrained texture. Use the sheet for proportions and silhouette.

## Allowed variation

The owner explicitly allows redrawing and creative changes. Poses, gestures, expression, composition, clothing details and shading may vary to suit the placement, while retaining a clearly recognizable character. The sheet is an identity reference, not a requirement to reproduce one pose or a locked outfit.

Use a single appropriate pose in a website section. The mountain/sun motif is a separate brand element that may accompany her. Do not place the full model sheet on the homepage.
